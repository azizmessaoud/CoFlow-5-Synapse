How they communicate

Shared Noticeboard

Agents post and read topics like state/, forecast/, and eco/. Every message has an expiry (TTL).

  • • If board is empty, A1 runs local rules.
  • • Asyncio pub/sub for simplicity.
  • • No tangles: agents don't call each other.

Formal Ask (Contract-Net)

For urgent needs (Ambulance/Buses), A2/A3 send a one-round request to A1.

  • • A1 replies: Accept or Reject + Reason.
  • • Priority: Safety > Emergency > Bus > Flow.
  • • No long bargaining: 5-second window.

Message failure test: We will drop messages on purpose to prove system stability.
