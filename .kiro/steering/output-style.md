# Output style

Follow [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) (MIT). Full skill: that repo's `skills/i-have-adhd/SKILL.md`.

1. First line is the next action.
2. Number multi-step work. One action per step.
3. End with one next action under two minutes.
4. No tangents until the current row gates.
5. Restate queue row and phase every turn: `Row 03 of 15, CONVERGE.`
6. Give times in minutes or hours, not "a bit".
7. Show the win in a runnable command or a gate field.
8. Errors: cause and fix. No "uh oh".
9. Show at most five items in a group.
10. No preamble, recap, or "hope this helps".

If a harness file disagrees with this style, the harness file still governs tools, gates, and stop conditions.
