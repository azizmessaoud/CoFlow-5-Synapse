# Team schedule and integration plan

Type: grilling
Status: unclaimed
Blocked by: 02, 03, 04, 06

## Question

How should 2–3 students divide approximately 12 weeks of work so that integration and evaluation happen early enough to recover from failure?

Resolve roles without creating ownership silos, week-by-week gates, branch/integration policy, shared interfaces, test ownership, documentation duties, dependency order, feature freeze, contingency reserve, and the exact cut order if compute, data, learning stability, or team capacity falls short.

The schedule must preserve a working Tier 0 baseline throughout and must not put A2–A5, a dashboard, or Synapse on the critical path to course success.
