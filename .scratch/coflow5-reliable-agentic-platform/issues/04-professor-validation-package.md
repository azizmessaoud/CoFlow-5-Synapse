## Question

What must the professor-facing walkthrough package contain to demonstrate the
J0 prototype, Tunis showcase, evidence lineage, failure behavior, and
limitations without presenting proxy validation as interviews or simulation as
deployment evidence?

## Answer

The professor-facing package requires one runnable offline walkthrough and one
frozen evidence index. The index links the J0 manifest, matched-seed baseline
comparison, specialist ablations, recovery-transition logs, read-only product
responses, and the Tunis showcase manifest.

The walkthrough order is:

1. establish frozen J0 evidence and fixed-time, actuated, and cooperative A1
   baselines;
2. show specialist ablations and injected recovery failures;
3. demonstrate Synapse `verified`, `template`, and `abstain` behavior, including
   that disabling Synapse does not change control actions;
4. show Tunis last as a separately labelled data-ingestion showcase.

Every result is labelled as one of measured J0 evidence, proposed target,
assumption, literature finding, or Tunis showcase observation. The package and
UI state that proxy validation is not interviewing, simulation is not
deployment evidence, HBEFA values are emission proxies, and simulated
emergency delay is not lives saved.

The walkthrough runs from frozen artifacts without a hosted LLM. Provider
unavailability is demonstrated through deterministic template fallback or
typed abstention and does not invalidate the package.
