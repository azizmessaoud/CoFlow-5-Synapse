## I-1 — Upper-tail reliability as a design target

| Field | Detail |
|---|---|
| **Insight** | For time-sensitive journeys, users may value predictable arrival more than a small reduction in average travel time; therefore the **upper tail** of journey time is a design target. |
| **Tunis practice** | CODATU–AFD: daily Grand Tunis congestion after modal shift — unreliable trips are a stated urban stress (context, not WTP). |
| **Transfer Evidence** | UK TAG A1.3 §6.3.3–6.3.4 reliability ratio **0.4** for car/non-freight LGV (appraisal values std. dev. separately from mean); FHWA reliability MOEs (P95, buffer, PTI). Supports **mechanism + metric method**, not Tunisian preference. |
| **Not Evidence** | “Users pay for certainty” as observed Tunis WTP; IMATM ▲ BTI 0.68 / 74% leave early. |
| **Owner** | David (primary). |
| **Metric** | P95 TT; buffer index / PTI; stops/veh; unfinished/teleported = failures. |
| **Solution seed** | Neighbour coordination; evaluate upper tail, not mean-only. |
| **SMART note** | P95 −5% vs MP under surge = proposed test. |

## I-4 — Wait, clearance, and completion are separate

| Field | Detail |
|---|---|
| **Insight** | Clearance assumptions vary by standard and user population; slower walkers can need substantially more time; **waiting** and **crossing completion** are separate service requirements; accessibility needs more than an app-only request. |
| **Tunis practice** | Mixed-age central crossings; app-only paths risk excluding low digital comfort (design implication, not survey %). MUTCD/HCM/ITE are **not** Tunisian legal requirements. |
| **Transfer Evidence** | Perceived wait ≈2× (Vallyon et al. ATRF/NZTA trail); ~20–30 s compliance stress (NZTA RR440 / TfL / DfT LTN 2/95 presets); MUTCD 1.07 m/s; HCM 1.0 m/s if many older users; ITE assistive ~0.6–0.8 m/s; Bentzen completion difficulties. |
| **Not Evidence** | IMATM ▲ 12 s/18 s / 19% unfinished; “MUTCD 2023 allows 0.8 m/s”; wait 1.5×. |
| **Owner** | Amara. |
| **Metric** | Call→WALK delay; wait mean/P95; % >30 s; clearance truncations; completion before conflicting green. |
| **Solution seed** | Accessible request + ack; wait-aware service; conservative clearance; hard interlock. |
| **SMART note** | Mean ≤20 / P95 ≤40 / cap 40 = proposed engineering criteria. |
