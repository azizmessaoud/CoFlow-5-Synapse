# 04: Completing the integrated incident and advisory loop

**What to build:** An end-to-end incident path in which detected or injected situations produce bounded A4/A5 advice, A1 dispositions, and safe behaviour through communication or model degradation.

**Blocked by:** 03: Proving pedestrian demand on J0.

**Status:** ready-for-agent

- [ ] An incident can be injected or represented with the canonical incident shape and traced through the system.
- [ ] A4 publishes bounded forecast or incident advice with source time, horizon, confidence, expiry, and model identity.
- [ ] A5 publishes proxy-labelled sustainability advice with displacement-aware context.
- [ ] A1 records accepted, rejected, deferred, or expired advice with reason codes.
- [ ] Missing, stale, malformed, or failed advisory inputs preserve legal local control and the recovery ladder.
- [ ] The integrated path is demonstrable without requiring an LLM or learned controller.
