# 09: Packaging the offline professor walkthrough

**What to build:** A runnable, frozen-artifact walkthrough and evidence index that demonstrates the J0 prototype, product safeguards, failure behavior, and limitations without requiring a hosted provider.

**Blocked by:** 08: Delivering the evidence-backed operator dashboard.

**Status:** ready-for-agent

- [ ] One offline command or script runs the walkthrough from frozen artifacts.
- [ ] An evidence index links the J0 manifest, matched-seed comparison, ablations, failure transitions, product responses, and showcase manifest.
- [ ] The walkthrough presents J0 baselines first, then ablations and failures, then Synapse fallback states.
- [ ] Hosted-provider unavailability produces deterministic template fallback or typed abstention.
- [ ] Every result carries an explicit claim category and the package states its limitations.
- [ ] Proxy validation is not described as interviewing, and simulation is not described as deployment evidence.
