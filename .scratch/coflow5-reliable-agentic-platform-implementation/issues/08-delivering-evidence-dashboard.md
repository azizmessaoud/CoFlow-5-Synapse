# 08: Delivering the evidence-backed operator dashboard

**What to build:** A read-only operator view that makes controller state, evidence, recovery, comparisons, citations, limitations, and audit outcomes inspectable without control authority.

**Blocked by:** 07: Delivering the read-only API boundary.

**Status:** ready-for-agent

- [x] Operators can inspect frozen runs, controller and recovery state, messages, decisions, and reason codes.
- [x] Baseline and ablation comparisons show matched-scenario context and honest null or negative results.
- [x] Explanations display event and policy citations plus the seven provenance fields.
- [x] Claim labels distinguish measured J0 evidence, targets, assumptions, literature findings, and Tunis showcase observations.
- [x] Abstention and fallback metrics are visible with their relevant dimensions.
- [x] The dashboard has no signal command, active-state mutation, or hidden domain-fact write path.

**Status:** complete
